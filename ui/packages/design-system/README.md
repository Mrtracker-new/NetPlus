# @netpulse/design-system

The single source of NetPulse's visual language
(`docs/0-foundation/04_Project_Structure.md` §4, `docs/01` §9): design tokens,
protocol iconography, and severity styles. One place defines what "TLS" looks
like and what "high severity" looks like, so every screen agrees. Components
import from here; nothing else defines colors or icons.

**Status: foundation stub.** Phase 2.
